# CamFlow

CamFlow is a lightweight, responsive desktop application built with Python and OpenCV for mobile camera streaming. It provides a smooth, low-latency live video feed with dynamic controls to record, pause, snapshot, and manage your media capture seamlessly.

## Features
* **Smooth Live Streaming:** Low-latency video feed and processing.
* **Dynamic Video Toggle:** Easily start, pause, and resume video recording on the fly.
* **Instant Snapshot Capture:** Take clean, high-resolution image snapshots instantly.
* **Keyboard-Driven Controls:** Control the entire application effortlessly using hotkeys.

## Keyboard Usage
* Press **'v'** to toggle video recording (start/pause).
* Press **'c'** to capture a snapshot image.
* Press **'q'** to exit the application.

## Installation
Install OpenCV using pip:
```bash
pip install opencv-python
```
